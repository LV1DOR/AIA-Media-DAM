# Search, quick tags, ZIP and dark theme

Prepared on `frontend/unified-ui-review`, 9 November 2026. Production has not been deployed or modified.

The library's quick tag action is visible on thumbnails without hovering. It opens the existing tag editor; bulk tag editing and native permission checks remain unchanged. The other thumbnail tools remain accessible too.

The review data search previously tested the entire combined text as a substring and omitted keywords, despite displaying those keywords in details. It now matches each independent chip across title, filename, event, championship, year and the current saved tags, without regard to case. This fixes the reported `MotoGP` + `2026` and `Racing` / `racing` cases in the local review. Each term must match; fields may differ between terms. The production query builder normalizes case and translates standalone four-digit years to an explicit `year` field constraint. It retains collection scope and existing metadata filters, and native search continues to enforce the signed-in user's access. It does not scan only the visible page or copy the library into a separate index.

The year field syntax follows [ResourceSpace's documented field search](https://www.resourcespace.com/knowledge-base/user/special-search-terms). Native general search covers [indexed metadata fields](https://www.resourcespace.com/knowledge-base/user/simple-search). The NAS at `192.168.250.80:8088` was unreachable during the current read-only connection attempts, so the current native search/index behavior is **not verified**. Failed probes are recorded in [native search evidence](evidence/native-search-before.json); no repair or database write was attempted. The demonstrated regression and its fix are in the synthetic preview.

Download All now requests one archive at `/api/public/:id/archive`. The API streams the original files through Archiver in ZIP STORE mode, with ZIP64 enabled. No decoding, resizing, quality setting or transcoding is applied. Duplicate names receive numbered suffixes, Unicode is retained and path components are removed. Original individual downloads remain available. There is no browser-wide buffer of the archive or temporary copy of the originals.

The archive route uses the same password grant, active/expiry/owner checks and native original-file source as individual downloads. One archive consumes **one download start**, allowing a single remaining start to retrieve all included files. The first original must be available before claiming that start. Incomplete manifests, revoked/expired links, missing grants and exhausted limits are rejected. Revocation or client disconnect stops the archive; later source failures abort the download rather than silently omitting files. Archive downloads must start from the beginning; resumable individual downloads are unchanged.

The phrase “Available on the AIA network.” has been removed. Dark surfaces now use neutral charcoal/black with grey borders, white text and white primary controls. Status colors and media pixels retain their meaning.
