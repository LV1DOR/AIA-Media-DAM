# AIA Media and Transfer quick guide

Media: https://192.168.250.80:8443 · Transfer: https://192.168.250.80:8444

These addresses work on the AIA network or an existing approved VPN. An outside recipient needs that connectivity too. IT must install the supplied AIA LAN CA certificate after checking its fingerprint; never bypass a certificate warning. First administrator credentials are in the private workstation owner-access file, not this repository. Enroll an authenticator when prompted, then change the initial password in Settings. Administrator MFA is required.

1. **Find media.** Search titles or indexed year, event, championship and tags. Choose Photos or Films. Switch between grid and list. Open a file for metadata, preview and an authorized original download. Video playback needs a supported browser codec.
2. **Contribute permanent media.** Completed uploads enter the library automatically; there is no Review page or manual approval. Media editors and administrators can edit metadata and add/remove tags. Bulk edits save per asset and report failures. Archive a file when it should leave the live library; archiving preserves its original. Existing legacy unpublished records are retained in ResourceSpace and are not mass-published by this change.
3. **Share library media.** Select library files and choose Share. Set a title, message, lifetime and optional recipient password. Copy the one Transfer link. Originals remain in ResourceSpace; this action does not upload them into temporary storage. A source permission or archive change can stop an existing share.
4. **Send temporary files.** Open Transfer directly and select up to 100 files, each no larger than 20 GiB. Set a lifetime (7 days by default; 30 maximum), optional password and optional shared download-start limit. Upload all files before the link becomes active. The recipient sees a file list and downloads individual files; there is no combined ZIP.
5. **Resume or retry.** Temporary uploads resume from confirmed 16 MiB chunks. Select exactly the same files in the original order, with the same names and sizes. Do not replace a file with different contents. Library uploads are whole-file uploads: cancel and retry incomplete files; completed files remain in the library. At 99%, server-side media processing may still be running.
6. **Manage links.** Open Transfer history to inspect either source, copy a link or revoke it. Revocation blocks gateway access immediately; source deletion/revocation retries if a backend is unavailable. Library originals survive. Already downloaded copies cannot be recalled. A download-start limit counts individual file requests, including restarted/range requests, not successful completed batches.
7. **Staff administration.** Administrators create staff in Settings with media editor, marketing or administrator roles. Library access creates a separate native identity automatically. Disabling staff ends sessions, blocks owned links immediately and queues native cleanup/account disable. Re-enable only after that cleanup completes. Administrators can reset a colleague's password in Settings; share it privately. Lost MFA recovery is available to the authenticated NAS operator through the runbook.

Transfer payloads are disposable and excluded from recurring backups. Backups retain permanent media and the registry, and restored links are quarantined. Do not use Transfer as an archive. No external upload requests, automated email or Transfer-to-library import are provided.
